# Legacy Web

Esta carpeta conserva la PWA original de AppFinanzas como referencia. La nueva arquitectura usa `mobile/` para la app Expo y `backend/` para la API propia.

Para abrir la version anterior:

```powershell
npx serve legacy-web
```

No coloques credenciales reales en `supabase-config.js`; esta version queda solo como historial funcional.
